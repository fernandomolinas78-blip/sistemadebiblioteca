Sistema de Biblioteca
Es un sistema que permite gestionar una biblioteca.
Control de entrada y salida de los libros, cantidad de visitantes, inventario.
Esta dirigido a los funcionarios bibliotecarios y al público en general que acude a la bilioteca.
Funcionalidades principales previstas son control de prestamos, control de inventario, control de personas que acuden a la biblioteca.
